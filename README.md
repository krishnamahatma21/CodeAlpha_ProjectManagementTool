# Project Management Tool

A full-stack collaborative project management application inspired by tools like Trello and Asana.

## Tech Stack

### Frontend
- React
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Authentication
- JWT
- bcrypt

## Planned Features

- User registration and login
- User authentication
- Create and manage projects
- Add project members
- Create and assign tasks
- Task status management
- Task comments
- Project boards
- Search and filtering
- Notifications
- Real-time updates
